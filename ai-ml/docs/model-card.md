# Phoenix AI/ML Model Card

## Purpose

This model card documents the AI/ML models used within Project Phoenix.

The models support the analysis of disaster-related cyber threats such as phishing, scams and misinformation.

## Intended Use

The AI/ML models are intended to support the Phoenix platform by analysing threat information and contributing to risk detection and risk scoring.
